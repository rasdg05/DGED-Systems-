# Entrega y precios

Se cotiza en **USD**. El comprador de nearshoring ya compara contra asesores americanos y contra el costo de equivocarse de predio. Una nave detenida por capacidad eléctrica cuesta más que esto en un mes de renta y nómina de proyecto.

No hay plan de $99. No hay “contacto para enterprise” vacío: hay tres ofertas.

## 1. Atlas Screening — el piloto

Lo que se firma en los primeros meses.

| | |
|---|---|
| Precio | **USD 55,000** |
| Plazo | 6 semanas desde coordenadas y pago del 50% |
| Incluye | Hasta 12 sitios en `nl-monterrey`, score base, 3 escenarios, memo, taller de 90 min, 5 lectores por 90 días |
| No incluye | Dictamen eléctrico, estudio hidrológico firmado, due diligence legal del predio, levantamiento de seguridad, segundo corredor |
| Precio alterno | USD 70,000 si DGED tiene que construir el universo de candidatos (el cliente no trae predios, trae “búsquenme dónde”) |

El 50% al firmar, 50% contra entrega del memo. Sin el primer pago no se enciende el portafolio: evita el piloto eterno “de buena fe”.

El memo tiene dueño con nombre del lado DGED. No lo firma un modelo.

## 2. Atlas Operate — anual, después del piloto

| | |
|---|---|
| Precio | **USD 96,000 / año** |
| Incluye | El mismo corredor, refresco trimestral de snapshots, re-score, 8 asientos, dos talleres al año, alerta cuando un sitio publicado cambia de factor en más de 8 puntos |
| Corredor extra | **USD 48,000 / año** (Bajío sería el primero). No se descuenta del piloto |
| Sitios extra | Paquetes de 10 sitios a USD 8,000 dentro del corredor ya cubierto |

La alerta no es un feed de noticias. Es “el snapshot de sequía de octubre movió el agua de este sitio”. Si no hay delta, no hay correo.

## 3. Atlas Portfolio — fondo o desarrollador con varios parques

| | |
|---|---|
| Precio | **USD 210,000 / año** |
| Incluye | Hasta 40 sitios, 2 corredores, los talleres de Operate, una sesión trimestral de comité |

No se vende antes de tener **dos** Screenings entregados. Si no, el portafolio es un descuento sobre un producto que todavía no existe.

## Qué recibe el cliente el día de la entrega

1. Memo HTML/PDF, 8–12 páginas: pregunta, mapa, tabla de ranking, ficha de los tres primeros y del peor, escenarios, evidencias, “qué no dice este estudio”.
2. Acceso de lectura al portafolio.
3. Hoja de supuestos: pesos, versión del modelo, cortes de cada snapshot, clase PRODESEN y quién la asignó.

## A quién se le ofrece primero

En este orden. Cinco conversaciones, no una campaña.

1. Desarrollador con parque en Pesquería, Apodaca, Salinas Victoria, Ciénega de Flores o García que esté cerrando un inquilino grande y no controla el tema eléctrico.
2. Corporativo de manufactura eligiendo entre dos predios ya ofertados. Es el ciclo más corto: la decisión tiene fecha.
3. Operador logístico abriendo cross-dock hacia Colombia. Aquí el factor que importa es ruta, y hay que decirlo.
4. Fondo industrial comparando un predio de NL contra uno del Bajío. El segundo corredor **no** se promete dentro de los USD 55,000. Se cotiza el comparativo como Screening doble o se espera a tener Bajío.
5. AMPIP como canal, después de tener un memo real que enseñar. Ellos ya tienen mapa de inventario con Colliers. No se compite contra ese mapa.

## Qué no se regatea

- Sacar la sección de limitaciones.
- Poner “MW disponibles” porque el cliente lo pide en la portada.
- Entregar el crudo de DENUE o la base OSM rehecha como si fuera de DGED.
- Precio por “usuario extra” en el piloto. El valor no está en el asiento.
